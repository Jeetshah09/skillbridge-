## 📌 Overview

SkillBridge is a smart internship and job finding platform designed to connect students, companies, and administrators on a single platform.

The main goal of SkillBridge is to reduce the gap between students and organizations by providing internship discovery, skill-based matching, application management, learning resources, and communication features.

The platform helps students find suitable internship opportunities based on their skills and interests while allowing companies to efficiently manage internship postings and applications.

* Create and manage personal profiles

* View learning resources

* Manage notifications

* Create company profile
* Post internship opportunities
* Manage posted internships
* View student applications

* Skill-based candidate matching
* Manage communication with students

## 👨‍💻 Admin Module

* Manage users
* Manage students and companies
* Monitor internships
* Manage reports
* Platform administration

# 🧠 Smart Skill Matching System

SkillBridge includes an intelligent skill matching feature that helps connect students with suitable internships.

The system analyzes:

* Student skills
* Internship requirements
* Technology preferences
* Experience level

and provides relevant internship recommendations.

# ⚙️ Installation & Setup

## Backend Setup

Navigate to backend folder:

```bash
cd Backend
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run backend server:

```bash
uvicorn app.main:app --reload
```

Backend will run on:

```
http://127.0.0.1:8000
```

---

## Frontend Setup

Navigate to frontend folder:

```bash
cd Frontend
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Frontend will run on:

```
http://localhost:3000
```
